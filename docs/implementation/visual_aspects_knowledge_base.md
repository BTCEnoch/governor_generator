# Visual Aspects Knowledge Base

## Overview
This document defines the complete knowledge base for visual aspects in the Enochian Governor system. Each trait category is defined with its mystical significance, gameplay purpose, and relationships to other traits.

## Core Principles

### 1. Deterministic Generation
All trait combinations must be deterministically generated from:
- Governor's Enochian name
- Position in the Watchtower system
- Aethyr associations
- Sacred number correspondences

### 2. Mystical Coherence
Traits must maintain consistency with:
- Traditional Enochian lore
- Sacred geometry principles
- Elemental associations
- Astrological correspondences

### 3. Gameplay Integration
Each trait must serve multiple purposes:
- Puzzle mechanics
- Ritual requirements
- Player progression
- Story elements
