# Lighthouse System Diagrams

This directory contains all system architecture and flow diagrams for the Lighthouse project. The diagrams are written in Mermaid markdown format for easy version control and maintenance.

## Directory Structure
- `system/` - High-level system architecture diagrams
- `flows/` - Sequence diagrams for key workflows
- `components/` - Individual component architecture diagrams

## Usage
These diagrams can be rendered using:
- GitHub's built-in Mermaid renderer
- VS Code with Mermaid extension
- [Mermaid Live Editor](https://mermaid.live)

## Diagram Types
1. System Architecture Diagrams
2. Sequence Diagrams
3. Component Diagrams
4. State Diagrams
5. Flow Charts
